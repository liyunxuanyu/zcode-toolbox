# 离线办公文档处理插件 - 安装包

## 包内容

- `plugins/offline-office-docs/`  插件源码（含脚本、模板、技能、命令）
- `plugins/marketplace.json`      本地测试市场清单
- `README.md`                     详细使用说明

## 安装步骤（目标 Windows 内网机器，ZCode 桌面端）

1. 将整个 zip 解压到本机任意目录（例如 `D:\zcode-ext\`），解压后得到 `plugins/` 目录。
2. 打开 ZCode → **插件市场 / Plugin Marketplace**。
3. 点击 **添加 / Add → 添加插件市场 / Add Plugin Marketplace**。
4. 粘贴或选择解压出来的 **plugins 目录**（其下应有 marketplace.json），例如：
   `D:\zcode-ext\plugins`
5. 添加成功后，进入 **个人 / Personal**，找到市场 **dev-offline-office-local** 下的
   **离线办公文档处理 (Offline Office Docs)**，点击 **安装 / Install**。
6. 新建任务，在输入框的技能/插件选择器中选中 **offline-office-docs**，发送任意文档处理指令试用。

## 快速验收示例

新建任务并发送（替换成你机器上的真实文件）：

> 读取 D:\docs\报告.docx 的结构，然后提取 D:\docs\报告.pdf 的全部文字

预期：输出 docx 的段落/表格统计和 PDF 的中文文本内容，全程无需联网。

## 环境要求

- Windows 10/11 或 Server 2016+（自带 Windows PowerShell 5.1 与 .NET Framework 4.x）
- 无需外网、无需 npm、无需 Python、无需管理员权限
- 可选：装有 MS Office 或 WPS Office 时，额外解锁 Office↔PDF 高保真互转
